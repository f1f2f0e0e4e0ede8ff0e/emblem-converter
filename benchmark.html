A Reconstruction Study

The Compression Benchmark

Thirty-five masterworks, each rebuilt as emblem code and placed beside the original.

An emblem editor stores a picture as a few hundred flat rectangles. Thirty-five masterworks are rebuilt under that limit and set beside the original, each measured for similarity and open to inspection up close.

Each tool converts the same 512×512 source; the result is rendered back to 512×512 and scored for Similarity to the original, 0 to 100, where 100 is identical. The underlying measure is the SSIM structural-similarity index.

Emblem Converter runs a single pass on stock settings. The other tool is run across all 84 settings it exposes and its closest fitting result is shown. Each is held to its own size limit: 1,250,000 and 1,280,000 encoded bytes. No per-work tuning was applied to Emblem Converter.

Sources: the open-access collections of Wikimedia Commons and partner museums, and NASA. Every work is public domain or CC0.
